# Taller Práctico Procesamiento del lenguaje natural con clasificación y espacios vectoriales

## Plataforma de laboratorios

Te damos la bienvenida a la **plataforma de laboratorios** del curso **Taller Práctico Procesamiento del lenguaje natural con clasificación y espacios vectoriales**. Aquí desarrollarás una solución de procesamiento del lenguaje natural para clasificar mensajes bancarios y recuperar casos similares, mediante prácticas guiadas con Python en Visual Studio Code.

## Lista de laboratorios

Cada uno de estos laboratorios está diseñado para ofrecerte una experiencia práctica. Haz clic en los enlaces para comenzar.

## Capítulo 1

### [Práctica 1. Clasificación y búsqueda de mensajes bancarios con NLP](Capitulo01/README.md)

- **Descripción**: Construye en un cuaderno de Jupyter una solución para limpiar mensajes bancarios sintéticos, representarlos con bolsa de palabras y TF-IDF, y clasificarlos en seis categorías mediante Naive Bayes y regresión logística. Evalúa los modelos, analiza errores y recupera mensajes similares con similitud coseno, distancia euclidiana y vecinos más cercanos. Finalmente, visualiza los mensajes con PCA y guarda el clasificador y el buscador para consultar nuevos casos.
- ⏱️ **Duración estimada**: 225 min (3 horas y 45 minutos).
- 📁 **Prerrequisitos**: [Preparación del entorno de laboratorio](Capitulo01/Prerrequisitos.md).
